# HHKB Type-S Cheat Sheet

## DIP Switches (on the back)

| Switch | OFF (default) | ON |
|---|---|---|
| **SW1** | Delete key = Delete | Delete key = Backspace |
| **SW2** | Windows/Linux mode | **macOS mode (use this)** |

> For macOS: **SW2 ON**, rest OFF. Diamond keys become Cmd.

## Bluetooth (Hybrid Type-S)

| Action | Shortcut |
|---|---|
| Pair new device | `Fn + Q` (hold 3 sec, LED flashes) |
| Connect to profile 1 | `Fn + Ctrl + 1` |
| Connect to profile 2 | `Fn + Ctrl + 2` |
| Connect to profile 3 | `Fn + Ctrl + 3` |
| Connect to profile 4 | `Fn + Ctrl + 4` |
| Switch to USB mode | `Fn + Ctrl + 0` |
| Check battery level | `Fn + Ctrl + B` (LED blinks) |

### Battery LED Indicators

| Blinks | Battery Level |
|---|---|
| 4 blinks | 75-100% |
| 3 blinks | 50-75% |
| 2 blinks | 25-50% |
| 1 blink | 0-25% (charge soon) |

## Key Layout Differences from Normal Keyboard

| Normal Keyboard | HHKB |
|---|---|
| Caps Lock | **Control** (best feature of HHKB) |
| Backspace (top-right) | `\` and `` ` `` (backtick) |
| Backspace | One row lower, right of `=` |
| Arrow keys | `Fn + [ / ; ' /` |
| F-keys | `Fn + number row` |
| Tilde `~` | `Fn + Shift + Esc` |
| Insert | `Fn + \` |
| Delete | `Fn + Backspace` |

## macOS Media Controls (with Fn)

| Shortcut | Action |
|---|---|
| `Fn + A` | Mute |
| `Fn + S` | Volume down |
| `Fn + D` | Volume up |

## Tips

- **Control at Caps Lock position** is the killer feature -- makes all Ctrl shortcuts ergonomic
- Pair with Vim keybindings for a fully arrow-key-free workflow
- The `Fn` key is bottom-right -- use your right pinky
- Topre switches with silencing rings (Type-S) means you can use it anywhere quietly
- The keyboard sleeps after 30 min of inactivity in Bluetooth mode -- press any key to wake
